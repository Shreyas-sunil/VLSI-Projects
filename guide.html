Guide

Career tracks

Track A AI Accelerator and GPU Design

Microarchitecture, systolic arrays, dataflow, quantised and sparse compute, memory hierarchy, RTL, FPGA prototyping and PPA.

Track B GPU System Software, CUDA and Firmware

CUDA kernels, profiling, memory hierarchy, runtimes and drivers, boot and firmware, heterogeneous CPU-GPU work.

Track C SoC Architecture

RISC-V cores and custom instructions, AXI and interconnect, DMA, caches, NoC, verification of interfaces, integration and system-level PPA.

Scoring rubric

Each project is scored 1-5 on six criteria (maximum 30). Scores are planning estimates so projects can be compared; they are not measurements. Rank by the quality of the engineering, not by buzzwords in the title.

#CriterionMeaning
1RelevanceHow directly the engineering work maps to the three career tracks. 5 = core skill for the track; 1 = bridge subject with a thin connection.
2Technical depthHow much real engineering understanding is needed. 5 = deep architecture, algorithms or physics; 1 = largely tool use or a direct application.
3Feasibility (low cost)Can it be finished with free tools and a laptop or modest hardware? 5 = fully open tools and CPU only; 1 = needs scarce hardware or heavy compute.
4Measurable evaluationQuality of the baseline and metrics. 5 = clear baseline, numeric metrics, repeatable measurement; 1 = mostly qualitative.
5Portfolio distinctivenessHow memorable the artifact is to a hiring manager. 5 = a verified, runnable hardware or software system; 1 = a document or small script.
6Research potentialCredible route to a workshop or conference paper. 5 = open question with a measurable contribution; 1 = no publishable angle. Most projects are student-level contributions.

Priority labels

  • Build first - a strong foundational or portfolio project.
  • Build next - a substantial intermediate project.
  • Stretch - advanced, resource-intensive or research-oriented.

Project card anatomy

Every card has: identification and syllabus mapping; the engineering problem; the proposed architecture with a module flow; a numbered implementation plan (study, build, artifact, gate); tools and alternatives; baseline, metrics and success criteria; deliverables; career value including a resume bullet and interview questions; risks, fallback and extensions; and the six-part score. Effort is shown in weeks and approximate focused hours assuming about 12 hours per week alongside coursework.

Evidence rules

Claim typeHow to treat it
Established techniquePublished and widely used; cite it.
Proposed design choiceA decision recommended in a project card; justify it when you build.
HypothesisSomething the project is designed to test; do not state it as a result.
Expected outcomeWhat would count as success; a target, not a promise.
Demonstrated resultOnly valid after you run the experiment. Label each result as measured, simulated, analytical estimate or design target.

Simulation, synthesis and place-and-route results are not silicon validation. A literature review shows a problem matters; it does not make your solution novel.

Syllabus audit and discrepancies

Course codes, titles, credits, units and practicals were cross-checked against the 2024 scheme PDF. The PDF itself contains inconsistencies; this site uses the index codes and notes the differences:

  • Algorithms for VLSI Design Automation: index code MVE331TA, course page code MVE361TA; page title reads "Algorithm for VLSI Design Automation".
  • Minor Project: index and credit table code MVE433P, guidelines page MVE443P.
  • Research Methodology: index and credit table MIM426RT, course page MIM416RT.
  • Electric Vehicle Technology - II: index title includes "II"; the course page title reads "Electric Vehicle Technology".
  • MVE341F3: the course page prints the code as "MV341F3"; MVE341F4: the index prints a stray "2" after the title; its header says 8 weeks but 12 weekly topics are listed.
  • Programming, Data Structures and Algorithms: the elective list shows the shorter title; the index and your checklist add "using Python".
  • NPTEL course pages carry indicative 2025 dates and are marked as subject to change with NPTEL's offerings.
  • Credit totals per the PDF: Semester I 19, II 23, III 18, IV 20.
  • Semester I lab is stated as 45 nm CMOS for the skill lab; open alternatives are sky130 or FreePDK45/NanGate45.

Total entries: 47 (matching your checklist), counting each elective option separately.
