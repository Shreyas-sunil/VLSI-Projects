Roadmap and dependencies

Do not treat the library as 147 separate projects. Build a small set of reusable assets, then specialise.

Five stages

Stage 1 - Digital, analog and embedded foundations

RTL and FPGA datapaths, timing with Tcl, embedded firmware on the lab board, analog building blocks, AI basics and technical writing.

MVE315AAMVE311TBMVE213IAMVE314TAMCS216TBHSS116EL

Start with MVE315AA-P1 (MAC array) and MVE315AA-P3 (RV32I core). They create the assets almost every later project reuses.

Stage 2 - Core VLSI engineering

Low-power design, analog and mixed-signal circuits, SystemVerilog and formal verification, test and DFT, physical design and its algorithms.

MVE212IAMVE221IAMVE222IAMVE223TAMVE224BAMVE315ADMVE332CA

Take the MAC array through synthesis, STA, power, scan insertion and a first OpenROAD run before adding features.

Stage 3 - Computer architecture and acceleration

Quantisation, dataflow and tiling, out-of-order and vector cores, GPU programming, parallel computing and number formats.

MVE315ABMVE315ACMVE224BCMMA325DNMVE333DDMIM426RT

Run the quantisation study early; its weights and the tile scheduler feed the minor and major projects.

Stage 4 - System integration and verification

UVM and register models, AXI/DMA integration, firmware and drivers, NoC and multicore, packaging and interconnect effects, PPA and end-to-end evaluation.

MVE231TAMVE434PMVE435NMVE333DBMVE333DCMVE332CDMVE341EA

Integrate before optimising: a verified end-to-end system beats several half-built blocks.

Stage 5 - Research-grade implementation

Pick one or two of the strongest ideas, extend them, and evaluate rigorously.

MVE442PAMVE341EDMVE341EBMVE341EC

Define the research gap with a literature map (MIM426RT-P1) before committing to a major project.

Semester-wise plan

Semester I - foundations and first assets

Build these first: MVE315AA-P1MVE315AA-P3MVE311TB-P2MVE212IA-P1MVE213IA-P1MVE314TA-P1MCS216TB-P3HSS116EL-P1

Prerequisites: basic Verilog, C, Python, digital logic. Reusable outputs: MAC array RTL with a golden model (MVE315AA-P1), an RV32I core (MVE315AA-P3), Tcl timing scripts, boot and driver code for the STM32F407 lab board, gm/ID lookup tables, an accelerator specification document.

Good coursework submissions: MVE311TB-P1, MVE213IA-P1, MVE314TA-P1, MCS216TB-P1. Worth expanding into portfolio pieces: MVE315AA-P3, MVE311TB-P2, MVE212IA-P2, MCS216TB-P3. Semester I now carries 23 of the 70 credits, so it has the most CGPA leverage. The current timetable offers only MVE315AA from Group A; if you are in a batch that picks another option, build MVE315AA-P1 anyway, because most later cards reuse the MAC array.

Semester II - analog, verification, test and measurement discipline

Build these first: MVE222IA-P2MVE222IA-P3MVE223TA-P2MVE221IA-P1MVE224BA-P2MVE224BC-P2MIS325DM-P3

Prerequisites: Semester I assets, a working OpenROAD/OpenLane install, basic SPICE. Reusable outputs: AXI VIP and protocol assertions, scan and BIST insertion scripts, op-amp and switched-capacitor blocks, physical-design sweep infrastructure (if you take MVE224BA), a CUDA optimisation ladder (if you take MVE224BC), a register generator.

Good coursework: MVE221IA-P1, MVE223TA-P1, MIM426RT-P1, HSS227TA-P1. Portfolio pieces: MVE222IA-P3, MVE223TA-P3, MVE224BA-P2 or MVE224BC-P3. Group B now sets your track emphasis: MVE224BA physical design (A/C), MVE224BB RF, MVE224BC GPU systems (B), MVE224BD automotive software (B/C). For the interdisciplinary elective, pick the one whose bridge project you will actually finish.

Semester III - UVM, integration and the minor project

Build these first: MVE434P-P1MVE434P-P2MVE231TA-P1MVE231TA-P2MVE333DB-P2MVE333DB-P3

Prerequisites: a verified MAC array, a register map, the AXI VIP from MVE222IA, a working flow runner. Reusable outputs: the accelerator block with AXI-Lite and DMA, a UVM environment and RAL model, a CUDA GEMM ladder with roofline, a NoC router and a SIMT core (if you take MVE333DB).

The internship (six weeks before Semester III) is assigned by the host or CoE: use the MVE435N plans only as proposals to agree with your mentor. Multicore Computer Architecture moved here from Semester IV, so the SIMT and NoC cards are now available a semester earlier for the major project.

Semester IV - the major project and research

Build these first: MVE442PA-P1MVE442PA-P2MVE442PA-P3MVE341EA-P1

Prerequisites: the minor-project accelerator, an RV32 core, a UVM environment, a literature map and a measurement database. The 18-week major project is individual and requires presenting or publishing the work.

Semester IV is only 7 credits on paper (major project 5 plus one 2-credit MOOC), but the major project is still 18 weeks of full-time work. Choose one major-project path and use the Group E MOOC as supporting study.

Prerequisite skills

  • Before accelerator projects: Verilog/SystemVerilog, fixed-point arithmetic, a golden model in Python, a working simulator.
  • Before physical design: synthesis and STA basics with Tcl (MVE311TB), Liberty and SDC.
  • Before CUDA work: C++ and the execution model (grids, blocks, warps), then memory hierarchy and profiling (MVE224BC Unit IV).
  • Before SoC integration: AXI handshakes, DMA, CSR conventions, RISC-V privileged basics, and a UVM environment (MVE231TA).
