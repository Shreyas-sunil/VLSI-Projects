Roadmap and dependencies

Do not treat the library as 141 separate projects. Build a small set of reusable assets, then specialise.

Five stages

Stage 1 - Digital and embedded foundations

Programming, RTL, FPGA datapaths, timing basics, embedded software and technical writing.

MCS214A1MVE214A4MVE313IAMVE311TAHSS116EL

Start with MVE214A4-P1 (MAC array) and MVE214A4-P3 (RV32I core). They create the assets almost every later project reuses.

Stage 2 - Core VLSI engineering

Low-power design, analog and layout fundamentals, physical design, SystemVerilog verification, synthesis and timing closure.

MVE212IAMVE321IAMVE322IAMVE323B1MVE427SLMVE415DLMVE323B3MVE324C4

Take the MAC array through synthesis, STA, power and a first OpenLane run before adding features.

Stage 3 - Computer architecture and acceleration

Quantisation, memory hierarchy, dataflow, number formats, parallel computing and architecture-level modelling.

MCS324C1MMA325DNMDC324C2MVE232E2MVE331TAMIM426RT

Run the quantisation study early; its weights and the tile scheduler feed the minor and major projects.

Stage 4 - System integration and optimisation

AXI/DMA integration, firmware and drivers, verification, benchmarking, PPA and end-to-end evaluation.

MVE433PMVE434NMVE232E1MVE232E3MVE341F1MVE341F4

Integrate before optimising: a verified end-to-end system beats several half-built blocks.

Stage 5 - Research-grade implementation

Pick one or two of the strongest ideas, extend them, and evaluate rigorously.

MVE442PMVE341F2MVE341F3

Define the research gap with a literature map (MIM426RT-P1) before committing to a major project.

Semester-wise plan

Semester I - foundations and first assets

Priority builds: MVE214A4-P1MVE214A4-P3MVE311TA-P2MVE212IA-P1MVE313IA-P1MCS214A1-P1HSS116EL-P1

Prerequisites: basic Verilog, C, Python, digital logic. Reusable outputs: MAC array RTL with a golden model, timing scripts, tile scheduler, boot/driver code, accelerator spec document.

Good coursework submissions: MVE311TA-P1, MVE313IA-P1, MCS214A1-P2. Worth expanding into portfolio pieces: MVE214A4-P3 (RV32I core), MVE311TA-P2, MVE212IA-P2.

Semester II - core VLSI and measurement discipline

Priority builds: MVE322IA-P1MVE322IA-P2MVE323B1-P2MVE323B1-P3MCS324C1-P1MIS325DM-P3MVE427SL-P2

Prerequisites: Semester I assets, a working OpenLane/OpenROAD install, basic SPICE. Reusable outputs: physical-design sweep infrastructure, AXI-Lite VIP, quantised weights and exports, register generator, mini cell library.

Good coursework: MVE321IA-P1, MVE427SL-P1, MIM426RT-P1. Portfolio pieces: MVE322IA-P2, MVE323B1-P3, MVE427SL-P2. Group D electives: pick the one whose bridge project you will actually finish; the others are optional.

Semester III - integration and the minor project

Priority builds: MVE433P-P1MVE433P-P2MVE331TA-P3MVE232E1-P3MVE232E3-P3

Prerequisites: a verified MAC array, a register map, a working flow runner. Reusable outputs: the accelerator block with AXI-Lite and DMA, CUDA GEMM ladder with roofline, EDA kernels.

The internship (six weeks before Semester III) is assigned by the host: use MVE434N plans only as proposals to agree with your mentor.

Semester IV - the major project and research

Priority builds: MVE442P-P1MVE442P-P2MVE442P-P3MVE341F4-P2MVE341F4-P3

Prerequisites: the minor-project accelerator, an RV32 core, a literature map and a measurement database. The 18-week major project is individual and requires presenting or publishing the work.

Choose one major project path and use the F-group NPTEL electives as supporting study and small side results.

Prerequisite skills

  • Before accelerator projects: Verilog/SystemVerilog, fixed-point arithmetic, a golden model in Python, a working simulator.
  • Before physical design: synthesis and STA basics (MVE311TA), Liberty and SDC.
  • Before CUDA work: C++ and the execution model (grids, blocks, warps), then memory hierarchy and profiling.
  • Before SoC integration: AXI handshakes, DMA, CSR conventions, RISC-V privileged basics.
