How to use this site

  1. Read the Guide for the track definitions, scoring rubric and evidence rules.
  2. Open your semester page and read the semester plan at the top; it names the projects to build first.
  3. Open a course, expand a project card, and follow the implementation plan. Use All projects to filter by track, difficulty or GPU need.
  4. Use the Roadmap to see which assets carry from one project to the next, and the Shortlists to choose portfolio and major-project candidates.
Honesty rules baked into every card: projects are plans, not results; numbers are targets until you measure them; simulation is not silicon; CUDA claims need CUDA hardware; the novelty of a student integration is stated as student-level unless you add a real contribution.
