How to use this site

  1. Check the Syllabus section for units and credits, and use the SGPA/CGPA calculator to track grades.
  2. If you used the 2024 edition, read What changed first: it maps every old project ID to its new one.
  3. Read the Guide for the track definitions, scoring rubric, evidence rules and the syllabus audit.
  4. Open your semester page and read the semester plan at the top; it names the projects to build first.
  5. Open a course, expand a project card, and follow the implementation plan. Use All projects to filter by track, difficulty or GPU need.
  6. Use the Roadmap to see which assets carry from one project to the next, and the Shortlists to choose portfolio and major-project candidates.
Rules every card follows: a project is a plan, not a result. Numbers are targets until you measure them. Simulation is not silicon. CUDA claims need CUDA hardware. A student integration counts as student-level work unless you add something new.
