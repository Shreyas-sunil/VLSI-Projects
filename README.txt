VLSI Engineering Project Playbook (static website), 2026 scheme
==============================================================
Open index.html in a browser, or upload this whole folder to any static host
(GitHub Pages, Netlify, Cloudflare Pages, S3, Nginx, Apache). No build step,
server code, database or internet connection is required; all pages use relative links.

Contents
  index.html                     Home
  semester-1.html .. -4.html     Projects by semester, then by subject
  syllabus.html                  Syllabus by semester with PDF text
  timetable.html                 Semester I class timetable (w.e.f. 28.10.2026) checked against the scheme
  gpa.html                       SGPA / CGPA calculator (70-credit 2026 scheme)
  explorer.html                  Filter/search all 147 projects
  changes.html                   What changed from the 2024 scheme: course and project ID map
  roadmap.html, shortlists.html  Dependencies, reuse, portfolio shortlists
  guide.html, tools.html         Tracks, rubric, evidence rules, syllabus audit, tool setup
  glossary.html, references.html, coverage.html
  books/semester-1/, -2/         Book PDFs (linked from the semester pages)
  projects.csv, projects.json    Inventory and full data
  projects-2024-retired.json     The 31 cards from dropped 2024 courses
  style.css, app.js, explorer.js, data.js

Important
  Projects are plans. Scores, effort and outcomes are estimates or targets until you build and measure.
  Reference entries marked 'recalled' should be checked before citing (see references.html).
