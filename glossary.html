Glossary

TermMeaning
ACSAdd-compare-select; the core step of a Viterbi decoder.
AMBAArm's family of on-chip bus protocols including AXI, AHB and APB.
ATPGAutomatic test pattern generation for manufacturing tests.
AXIAdvanced eXtensible Interface; a high-performance on-chip bus protocol with separate address, data and response channels.
bfloat1616-bit floating point format with an 8-bit exponent, common in AI training and inference.
BISTBuilt-in self-test; test logic placed on the chip itself.
CDCClock-domain crossing; passing signals between asynchronous clocks safely.
CTSClock tree synthesis.
CUDANVIDIA's programming platform for GPU kernels.
DataflowThe scheduling of which data stays in place and which moves in an accelerator (for example weight stationary).
DFTDesign for test.
DMADirect memory access; moves data without CPU involvement.
DRC / LVSDesign rule check / layout versus schematic.
DSEDesign-space exploration.
ENOBEffective number of bits of an ADC.
FmaxMaximum clock frequency at which a design meets timing.
GEMMGeneral matrix-matrix multiplication.
HLSHigh-level synthesis from C/C++ to RTL.
HPWLHalf-perimeter wirelength; a standard placement metric.
ICGIntegrated clock-gating cell.
INL / DNLIntegral / differential non-linearity of a converter.
LECLogic equivalence check.
Liberty (.lib)Cell timing and power library format used by synthesis and STA.
MACMultiply-accumulate operation or unit.
MESICache coherence protocol with Modified, Exclusive, Shared, Invalid states.
MISR / LFSRMultiple-input signature register / linear-feedback shift register used in BIST.
NLDMNon-linear delay model: lookup tables of delay and slew in Liberty.
NoCNetwork-on-chip.
OccupancyRatio of active warps to the maximum an SM supports.
OCVOn-chip variation; timing margins for within-die variation.
PDNPower delivery network.
PEXParasitic extraction.
PMPRISC-V physical memory protection.
PPAPower, performance and area.
PTQ / QATPost-training quantisation / quantisation-aware training.
RooflineA model bounding performance by compute peak and memory bandwidth versus operational intensity.
RTLRegister-transfer level hardware description.
SDCSynopsys Design Constraints format for timing constraints.
SDC (fault)Silent data corruption: a fault that changes output without detection.
SDFStandard delay format for back-annotation.
SIMTSingle instruction, multiple threads; the GPU execution model.
SMStreaming multiprocessor in an NVIDIA GPU.
SoCSystem on chip.
SQNRSignal-to-quantisation-noise ratio.
STAStatic timing analysis.
SVASystemVerilog Assertions.
Systolic arrayA grid of processing elements passing data rhythmically between neighbours.
TNS / WNSTotal / worst negative slack.
TVLATest vector leakage assessment, a statistical method for side-channel leakage checks.
UPFUnified Power Format for describing power intent.
UVMUniversal Verification Methodology.
VCDValue change dump; waveform file format.
WarpGroup of 32 GPU threads executing in lockstep on NVIDIA hardware.
Weight stationaryDataflow where weights stay in PEs while activations stream.
